## Start here

Strands harness is built with the Harness SDK. Both are customizable. The difference is your starting point.

### Strands harness

Start with a preconfigured agent that includes tools, context management, sessions, and memory. Keep the defaults you like and change what you need.

[Get started with Strands harness →](https://strandsagents.com/docs/user-guide/harness/quickstart/)

### Harness SDK

If instead you want to build your agent from the ground up, reach for the Harness SDK. Choose your models and tools, then configure how your agent manages context, sessions, and memory.

[Get started with the Harness SDK →](https://strandsagents.com/docs/user-guide/sdk/quickstart/overview/)

## Build with us

Bring a question, an experiment, or something you're proud of to [Discord](https://discord.gg/strands) or [GitHub Discussions](https://github.com/strands-agents/harness-sdk/discussions). You don't need a finished project to join the conversation.

A bug report, a useful example, or one clearer sentence in the docs can make someone else's day easier. [Here's how to contribute](https://github.com/strands-agents/harness-sdk/blob/main/CONTRIBUTING.md).
